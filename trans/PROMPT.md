# 번역 지시 (지휘봉의 행방 한글패치)

당신은 일본어→한국어 게임 번역가입니다. 외부 번역기/웹 번역을 절대 사용하지 말고 직접 번역하세요.
작업 폴더: D:\nds\지휘봉의행방\work\translation

1. 먼저 glossary.md 를 읽고 고유명사·용어를 그대로 따르세요.
2. 맡은 묶음 src/NNN.json (각 항목 {id, where, ja}) 을 읽고, out/NNN.json 에 {"<id>": "<한국어>"} 형태의 JSON 객체로 모든 id를 빠짐없이 저장하세요. (UTF-8, ensure_ascii 없이)
3. 규칙
   - 문맥: 1600년 세키가하라 전투를 다룬 역사 어드벤처. 사극풍 자연스러운 한국어. 무장은 하오체/하게체/반말 등 인물 성격에 맞게, 이야기꾼(語り)은 "~지요/~습니다" 공손체. 같은 묶음 안 앞뒤 대사의 흐름을 고려하세요.
   - 줄바꿈 "\n" 위치는 자유롭게 바꿀 수 있지만, 한 줄은 공백 포함 **최대 16글자**, 줄 수는 원문 줄 수 이하(원문이 1줄이면 16자 초과 시 2줄까지 허용, 단 where가 숫자인 대사는 최대 3줄).
   - 【終】【注】【心】【シ】【言】【鋭音】【謎音】 같은 【】 태그는 원문과 같은 순서·같은 의미 위치에 그대로 넣으세요(글자수에 미포함). 【注】…【終】 사이는 강조 구간이므로 대응하는 한국어 단어를 감싸세요.
   - 사용 가능한 문자: 한글 완성형, 반각 숫자·영문, 전각 문장부호（、。…！？「」『』（）・：〜ー―☆★○●◆■→ 등 원문에 있던 기호). 한자·가나는 쓰지 마세요(태그 안 제외). 원문의 "……"는 "……"로 유지.
   - 루비 "漢字（よみ）"는 독음만 남기고 괄호 읽기는 지우세요.
   - 문자열이 "/" 로 시작하거나 끝나는 등 조각(조사·어미만 있는 문장 조각)일 경우 앞에 이름이 붙는다는 점을 고려해 "~의 정보를 입수했다." 처럼 자연스럽게 만드세요.
   - 효과음(「ワー……」 등)은 한국어 의성어로.
   - 일본어 그대로 남는 문자열이 없도록 하세요.
4. 완료 후 python 으로 out/NNN.json 을 열어 id 개수가 src 와 같은지, 16자 초과 줄이 없는지 스스로 검사하고 고치세요. (검사: 태그 제거 후 각 줄 len ≤ 16)
5. 결과 보고는 "NNN 완료, 항목 수" 한 줄씩만.
