# 작업 계획과 진행
1. ROM 분석: LINKDATA(인덱스+데이터), ARM9 BLZ, 폰트(LINKDATA 0, 64열×14px 셀), 문자표(ARM9 0x2051C34, 1594자).
2. 스크립트 파서(712~734·711·735) → 고유 문자열 추출 → 용어집 → 47묶음 병렬 직접 번역.
3. 폰트·인코딩·ARM9 폭 훅 → 빌드 → 헤드리스 DeSmuME 검증.
4. 그림 글자: 셀(OBJ)·비트맵·PACK(LZ11)·3D 텍스처 전수 조사 후 한글화.
5. 화면 대조로 남은 일본어·깨짐 전수 수정 → 재빌드·검증 → xdelta 배포.
