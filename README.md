# 지휘봉의 행방 NDS 한글패치 1.0.0

일본판 『采配のゆくえ』(코에이, 2008)의 한국어 패치입니다. 대사·선택지·인물 사전과 그림 글자를 외부 기계 번역 없이 직접 번역했습니다.

## 파일과 적용
릴리즈의 `Saihai_no_Yukue_KR.xdelta`를 원본 ROM에 적용합니다. 원본은 일본판 CI8J이며 SHA-256은 다음과 같습니다.

`d30f73b31e3083a28a405786c6e83abd465c6304f322b7b137b850746b3a216f`

```powershell
.\xdelta.exe -d -s "Saihai no Yukue (Japan).nds" Saihai_no_Yukue_KR.xdelta "지휘봉의행방_한국어.nds"
```

결과 ROM SHA-256: `a3f7911ec03deef6dfa6b8fbf96b443cd744ab330c8a44524115b6a8f2d7eb0a`. 패치는 `-0 -S none`으로 생성했고 복원 결과의 해시 일치를 확인했습니다. ROM은 배포하지 않습니다.

## 번역 범위
- 스크립트(LINKDATA 711~735): 고유 문자열 18,629개(약 34만 자). 대사, 선택지·명령·장소·소지품 목록, 인물 사전, 메모.
- 그림 글자
  - 타이틀 로고·안내문·시작 메뉴, 화 제목 카드, 장소·시간 자막 120장, 지도 방위
  - UI 아틀라스(사용·인물·주목·소지품·상세·돌아가기·말의 잎·보고·전령·지도·정보·발언·선택 등), 정보 화면 탭, 저장 메뉴, 오류창
  - 인물 머리말·선택지 버튼 텍스처 612장, 인물·소지품 설명 텍스처 191장
  - 화자 이름표 77개, 인물 이름 컷인 50명, 연출 문자(개시·성공·실패·설득·승리·패배·합전·보고·전령·천안 개시)
  - 전투 작전 패널 7장, 전투 지도 부대 이름표 326칸
  - 인물 카드 27장, 스태프 크레딧, 엔딩 화면

## 폰트
- 본문은 원본 13px 고딕 비트맵과 가장 비슷한 갈무리11. 한자·가나 글리프 자리에 한글 1,062자를 배정했습니다.
- 원래 모든 글자가 14px 고정폭이라 ARM9 문자표 탐색 함수를 줄여 만든 공간에 폭 훅을 넣어 글자 12px, 공백 6px로 바꿨습니다.
- 큰 그림 글자는 서울한강체·나눔스퀘어 네오, 작은 그림 글자는 갈무리 7/9/11.

## 구조 메모
- 스크립트는 SJIS 문자열을 담은 가변 길이 레코드 열(길이 워드, 블록 헤더 가변부)이며 【終】【注】 등 태그는 원문 바이트를 유지합니다.
- 메뉴·선택지 대부분은 3D 텍스처(선형 4bpp)입니다. 화자 이름표는 아래 8줄이 한 타일 왼쪽에 저장되고, 정보 화면 탭과 저장 메뉴 일부는 세로 1/2로 압축돼 있어 그에 맞춰 그렸습니다.

## 검증과 한계
- 창 없는 DeSmuME 코어를 내부 API로 조작해 콜드 부팅부터 오프닝, 제1화 대화, 첫 전투 지도, 선택지, 정보 화면(인물·소지품 설명)을 확인했습니다. 전체 플레이·실기 검증은 하지 않았습니다.
- 전투 지도 부대 이름표는 원본 글자가 약 5px라 전투별 참전 무장 명단과 픽셀 대조로 판정했습니다. 일부 칸은 이름이 틀렸을 수 있습니다.
- 스태프 이름은 일반적인 독음으로 적었습니다. 배경의 이시다 가문 문장 「大一大万大吉」은 그대로 두었습니다.

## 재현
Python 3.13과 `requirements.txt`. 원본 ROM을 상위 폴더에 두고 `tools/extract.py`로 원문 목록을 만든 뒤 `tools/build.py`로 빌드합니다. 번역 원고는 `trans/out/*.json`(단위 id별 한국어), 그림 글자 원고는 `trans/graphics`·`trans/tex2k`·`trans/labels`, 용어집은 `trans/glossary.md`입니다. 갈무리 BDF와 서울한강체·나눔스퀘어 네오 TTF는 별도로 내려받아 `fonts/`와 상위 폴더에 둡니다.
